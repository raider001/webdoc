# Getting Started

Testing how cool this is!

## How to navigate

There are three ways to move around, and they are deliberately different.

### The document tree

Open the hamburger button (top-left) to see every document in the library,
grouped by folder. This moves you *between* documents.

### The table of contents

The left pane lists the headings of the page you are reading. It moves you
*within* the current document.

### The map

The map button (top-right) opens a visual graph of how documents connect,
based on each page's metadata. More on that in the next document.

## What to read next

When you finish a page, the footer offers a suggested next document. Head to
the graph model to see how those suggestions are wired up.
